# Comskills Circle

The private community platform for the **Comskills Fellowship**: members pitch projects and find teammates, track scholarship applications, read team announcements, and share opportunities that the AI matches to the right people.

Built from Compass (Next.js 16, MongoDB Atlas, next-auth, Tailwind, Motion, d3-force). Runs on free tiers: Vercel Hobby, Atlas M0, Gemini free tier and Gmail SMTP.

> The full deploy guide is written in the last build phase.
